# Privacy Policy

_Last updated: September 2026_

SchemaSmith does not collect, transmit, or store any of your data on external servers. All generated code is written directly to your local project files.

Database connection details (host, port, database name, username, connection type) are stored locally using IntelliJ's built-in persistent settings storage. Database passwords are stored securely using your operating system's native credential store (Windows Credential Manager, macOS Keychain, or your configured Linux credential store) via IntelliJ's PasswordSafe API — never in plain text, and never transmitted anywhere outside your own machine.

SchemaSmith does not use analytics, telemetry, or any third-party tracking.
